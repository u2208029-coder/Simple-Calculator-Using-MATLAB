# Simple MATLAB Calculator

## Description
This project is a simple calculator developed using MATLAB. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- MATLAB

## File
- `calculator.m`

## How to Run
1. Open MATLAB
2. Open the project folder
3. Run the file:
   ```matlab
   calculator
